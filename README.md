# Sripada Multi-Speciality Hospitals

A modern, responsive website for Sripada Multi-Speciality Hospitals built with Next.js 15, TypeScript, and Tailwind CSS.

## 🏥 About

Sripada Hospital is a trusted healthcare destination combining Allopathy, Ayurveda, and Rehabilitation services under one roof. This website showcases our comprehensive healthcare services, facilities, and allows patients to book appointments online.

## ✨ Features

- **Modern Design**: Clean, professional healthcare website design
- **Responsive**: Fully optimized for desktop, tablet, and mobile devices
- **Multi-Specialty Services**: Comprehensive information about Allopathy, Ayurveda, and Rehabilitation
- **Online Appointment Booking**: Integrated appointment booking system
- **Facility Showcase**: Visual gallery of hospital facilities and services
- **24/7 Emergency Contact**: Easy access to emergency services
- **SEO Optimized**: Built with SEO best practices for better search visibility

## 🚀 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **UI Components**: Radix UI + Custom Components
- **Icons**: Lucide React
- **Analytics**: Vercel Analytics
- **Animations**: Framer Motion
- **Deployment**: Vercel

## 🚦 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn or pnpm

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
npm start
```
